# Physics Worked Problems

Step-by-step solutions to introductory physics problems (kinematics, forces, energy, circuits), each with the answer checked by a second method or a units check, plus a list of the most common mistakes in physics explanations.

## Contents
| File | Topic |
|---|---|
| [`mechanics.md`](mechanics.md) | Motion with constant acceleration, free fall, projectiles, Newton's laws, energy |
| [`circuits.md`](circuits.md) | Ohm's law, power, series and parallel resistors |
| [`common-mistakes.md`](common-mistakes.md) | Frequent errors in physics answers and how to catch them |

## Conventions
- SI units throughout (m, s, kg, N, J, V, A, Ω)
- g = 9.8 m/s² near Earth's surface unless stated
- Air resistance ignored unless stated
- Results rounded to 3 significant figures

## How each solution is written
1. **Given:** list the known quantities with units
2. **Find:** state what is asked
3. **Equation:** choose and justify the formula
4. **Solve:** substitute with units
5. **Check:** units, sign, order of magnitude, or a second method
